## ZBM2 CW Tool 3.5.1 - privacy + code-signing prep

- **Privacy page** ([PRIVACY.md](https://github.com/ko6ejv/zbm2-cw-tool/blob/main/PRIVACY.md)), shown in the Windows installer, with checkboxes for each internet feature (update check, band conditions, live CW spots). All three can also be switched off any time in Rig Setup.
- Band conditions now have their own on/off switch.
- The exe carries its product name and version (needed for code signing, which is being set up with SignPath Foundation).

Already on 3.4.1 or newer? Click the orange **NEW VERSION** button.
