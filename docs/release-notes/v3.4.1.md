## ZBM2 CW Tool 3.4.1 - one-click updates

**CW for people who can't copy CW yet. Putting competent operators on the net.**

### New
- **Update notice + one-click update.** At startup the app checks GitHub. If a newer version is out, an orange **NEW VERSION x.y.z - click to update** button appears under the title. Windows: downloads the new installer, installs over the old one (settings and log kept) and reopens. uConsole / Raspberry Pi: `git pull` and restart.
- HELP > **Check for updates**; startup check can be turned off in Rig Setup.
- **Always-latest download link:** https://github.com/ko6ejv/zbm2-cw-tool/releases/latest/download/ZBM2-CW-Tool-Setup.exe

### Install
- **Windows:** download `ZBM2-CW-Tool-Setup.exe` below.
- **uConsole CM4 / CM5, Raspberry Pi OS 64-bit:** `curl -fsSL https://raw.githubusercontent.com/ko6ejv/zbm2-cw-tool/main/install_uconsole.sh | bash`
