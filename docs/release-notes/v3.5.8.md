## ZBM2 CW Tool 3.5.8

- **Expert mode** (Settings > Keying): use your own paddle or keyer. The app never transmits, keeps decoding the other station, fills in call / RST / name / QTH, and **LOG** still logs the contact.
- SPOTS, HELP and Settings open one window each; clicking again brings it to the front.
- **What's new** window after each update (also under HELP).
- Yaesu FT-991 / FT-991A preset.

Already on 3.4.1 or newer? Click the blinking **NEW VERSION** button.
