## ZBM2 CW Tool 3.3.1 - uConsole CM5

**CW for people who can't copy CW yet. Putting competent operators on the net.**

### New
- **ClockworkPi uConsole CM5 support.** Same one-line installer as the CM4. It reports the board and OS, checks the CM5 overlay (`clockworkpi-uconsole-cm5`) and warns when a CM5 has no Wi-Fi.
- Tested on every change on ARM64 Debian **Bookworm** (Python 3.11) and **Trixie** (Python 3.13), the bases of the CM4 and CM5 uConsole images.
- Neural decoder threads scale with the CPU (half the cores); override with `"neural_threads"` in config.json.

### Install
- **Windows:** download `ZBM2-CW-Tool-Setup-3.3.1.exe` below.
- **uConsole CM4 / CM5, Raspberry Pi OS 64-bit:**
  ```
  curl -fsSL https://raw.githubusercontent.com/ko6ejv/zbm2-cw-tool/main/install_uconsole.sh | bash
  ```
  Already installed? Run the same line again to update.

CM5 notes are in the [README](https://github.com/ko6ejv/zbm2-cw-tool#clockworkpi-uconsole-cm4--cm5--raspberry-pi).
