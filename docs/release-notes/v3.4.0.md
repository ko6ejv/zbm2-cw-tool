## ZBM2 CW Tool 3.4.0 - band, tune, conditions, live dits

**CW for people who can't copy CW yet. Putting competent operators on the net.**

### New
- **BAND list next to the frequency.** One click changes band by CAT. It returns to where you last were on that band, else a common CW frequency.
- **TUNE button.** Starts the radio's antenna tuner by CAT (FTX-1, FT-891 / FT-991A with ATU, and any radio Hamlib can tune). Radios without a CAT tuner command can send a 5-second carrier for an automatic tuner (LDG etc.), after asking.
- **Band conditions** (N0NBH / hamqsl.com) when online: 80-40, 30-20, 17-15, 12-10, day and night dots. Green good, yellow fair, red poor. Hover for SFI, K and noise.
- **Live dits and dahs** over the spectrum: orange while receiving, red while you send.
- The station line shows how you really key and switch (e.g. `key: DTR COM3 | PTT: break-in`).

### Install
- **Windows:** download `ZBM2-CW-Tool-Setup-3.4.0.exe` below.
- **uConsole CM4 / CM5, Raspberry Pi OS 64-bit:** `curl -fsSL https://raw.githubusercontent.com/ko6ejv/zbm2-cw-tool/main/install_uconsole.sh | bash` (run again to update).
